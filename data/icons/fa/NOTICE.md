# Font Awesome Pro outlines

These JSON files hold SVG path outlines for about 100 icons, extracted by `tools/maintenance/build-fa-icons.py`
from the Font Awesome Pro 7.3.1 webfonts in `assets/` (Copyright 2026 Fonticons, Inc.,
https://fontawesome.com/license, Commercial License). Only the outlines the shell uses are kept; the full
webfonts are not shipped in the runtime or the OE image.

Font Awesome Pro is commercial software: confirm your license covers redistributing these derived outlines
before publishing the repository or an image build.
