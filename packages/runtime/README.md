# @dev-os/runtime

GJS runtime library for Dev OS. Import from `@dev-os/runtime` or its exported subpaths. Set `DEV_OS_ROOT` to the host assets directory when using an installed package.

Build the archive with `npm run runtime:pack`.

`@dev-os/runtime/lock` exports `LockScreen` and themed swaylock arguments. See
[lock screen setup](../../docs/lock-screen.md) for the native dependency and configuration.
