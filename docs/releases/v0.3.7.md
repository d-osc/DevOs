# DevOs v0.3.7

First release cut from the `ux3407na-dev` branch, the development line for the ASUS Zenbook A14/S 14 (UX3407NA, Snapdragon X2 Elite, ARM64). It follows v0.3.6 (2026-10-05) and covers the Dev OS desktop split into libraries and everything added since, up to the commit this release is cut from. **Treat it as a development snapshot, not a stable release.**

## Hardware status

The Live USB image builds and boots in QEMU (`virt`, ARM64). On the UX3407NA itself almost everything is **untested or only partly tested**, based on a handful of real boot logs from 2026-10-23 and 2026-10-24:

- Not verified on the laptop: native boot to the desktop after the latest splash changes, display, USB, Wi-Fi (board data and firmware were missing in early logs), Bluetooth pairing, speakers (audio topology was missing), touch, and suspend/resume.
- Sleep: a black screen that did not wake was reported before the ASUS EC driver and device-tree nodes were added. The fix is in the tree but unconfirmed on hardware; lid suspend stays disabled.
- Camera: the camera is MIPI (CAMSS/OV02C10) and the device tree has no camera graph yet, so there is no `/dev/video*`. Camera is unsupported.
- Boot splash: the black screen seen on the laptop has not been confirmed fixed. The splash no longer switches the console to graphics mode and logs to `DEVOS-LOGS` on the Live USB.
- The MyASUS-style controls below work through validated helpers and are covered by tests, but they need ASUS firmware interfaces; where the hardware is missing they are disabled with an explanation.

## What is in this release

- **Desktop**: GJS and React-to-GTK3 shell on labwc, split into libraries; native lock screen; Task Manager and Task View; Wi-Fi, Bluetooth, time, language, accounts, disks, printers, terminal and theme settings; Dark/Light 2026 themes with thin borders; a mesh-gradient default wallpaper and five animated wallpapers; Font Awesome icon packs in development builds only (see below).
- **MyASUS-style settings**: Battery Care Mode and Instant Full-Charge, Fan Profile, AI noise-canceling microphone and Volume Booster, OLED Care, Flicker-Free Dimming, Splendid, Target Mode, Touchpad lock and Smart Gestures, Function key and keyboard backlight, TaskFirst and WiFi SmartConnect.
- **Memory**: zram swap sized to RAM with a Memory and swap settings card, tighter systemd limits, lighter polling.
- **Live USB and installer**: ARM64 OpenEmbedded Live image tooling, hardware profiles (`profiles/asus/ux3407na`), a login greeter with Sleep, Restart and Shutdown, hardware and boot diagnostics written to `DEVOS-LOGS`, installer fixes that report the failing step. Node.js is no longer in the image; users install it with nvm. `sudo` and `curl` are included.
- **System helpers** run on DevLang 0.5.5.

## Assets

- `dev-os-linux-x64.tar.gz` and `dev-os-linux-arm64.tar.gz`: update packages for Settings > Updates.
- `devos-0.3.7-runtime.tar.gz`: the desktop payload the OpenEmbedded image build consumes (top directory `devos-runtime/`), including the hardware profiles.
- `devos-0.3.7-source.tar.gz` and `SHA256SUMS`.

There is **no Live USB image** in this release: it needs a long OpenEmbedded build, is about 6 GB, and GitHub release assets are limited to 2 GiB. Build it with `tools/live/release-live-usb.ps1` (see `docs/live-usb.md`).

The Font Awesome files (`assets/`, `data/icons/fa/` with its `NOTICE.md`) are included in the source and runtime archives and the update packages. Archives and checksums were produced by GitHub Actions; `SHA256SUMS.sig` is present only if a release signing key is configured.
