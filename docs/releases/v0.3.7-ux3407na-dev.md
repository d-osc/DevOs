# DevOs v0.3.7-ux3407na-dev

Development release for the ASUS Zenbook UX3407NA. This is a GitHub prerelease and is not offered by the stable update channel.

## Changes

- Merge the Live USB fixes into the main development tree, including boot splash milestones, installer tooling and hardware settings.
- Add the built-in browser and refresh application icons and desktop integration.
- Move additional keyboard, display, audio, touchpad and USB helpers to DevLang.
- Fix the keyboard backlight test race when reading a brightness file during a write.
- Add update package manifests, file-level patches, checksum signing support and system update bundles with rollback.
- Share the release pipeline between manual and tag builds, with branch selection and release notes read from this file.

## Release assets

- `dev-os-linux-x64.tar.gz` and `dev-os-linux-arm64.tar.gz`: full desktop update packages. Their internal version is `0.3.7`.
- `dev-os-patch-<previous>-to-0.3.7-<platform>.tar.gz`: generated when the previous published release has a compatible package manifest.
- `devos-0.3.7-ux3407na-dev-runtime.tar.gz` and `devos-0.3.7-ux3407na-dev-source.tar.gz`: runtime payload and tracked sources.
- `SHA256SUMS`, plus `SHA256SUMS.sig` when a release signing key is configured.
- When `build_image` is selected: `devos-live-0.3.7-ux3407na-dev-arm64-ux3407na.img.zst.part-NN` and `IMAGE-INFO.txt` with reassembly instructions.
- When `build_system_bundle` is selected: `dev-os-system-linux-arm64.tar.gz` and `dev-os-system-linux-arm64.json`.

Image and system bundle builds require a configured ARM64 image runner, kernel bundle and firmware inputs. Selecting an option does not imply these assets have already been built.

## Validation and hardware status

Build, TypeScript, update installation, patch, rollback and system update tests passed during integration. These checks use simulated hardware and do not establish that the image boots on the laptop.

Boot splash, display, keyboard, Wi-Fi, Bluetooth, audio and suspend/resume still need validation on the UX3407NA for this release. The MIPI camera is not confirmed working. Treat this release as a development build, not a hardware-qualified stable release.
